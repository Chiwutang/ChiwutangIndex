# 静态公告

编辑 `announcements.json` 后重新构建网站即可更新消息列表与正文。JSON 在构建时直接打包，页面不请求公告接口，也不需要 GitHub Token。

每项字段：

- `number`：唯一的正整数编号，对应 `/news/<number>`。已发布编号请保持不变。
- `title`：公告标题。
- `date`：带时区的公告日期，用于排序与显示。
- `author`：显示的署名。
- `summary`：列表摘要，可留空。
- `body`：Markdown 正文，支持站内链接（如 `/book`）与刊物外链。
